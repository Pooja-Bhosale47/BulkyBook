# Bulky Book Web Application

## 📌 Description
ASP.NET Core MVC application with Identity authentication, Entity Framework Core, and repository pattern.

## 🚀 Features
- User Registration & Login (Identity)
- Product & Category Management (CRUD)
- Clean Architecture
- SQL Server Integration
- Dependency Injection (DI)

## 🛠 Tech Stack
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server
- Identity
- Bootstrap

## ▶️ How to Run
1. Clone the repo
2. Update connection string in appsettings.json
3. Apply migrations:
   dotnet ef database update
4. Run the project

## 🔐 Authentication
- ASP.NET Core Identity used for user authentication
- Supports user registration and login functionality
